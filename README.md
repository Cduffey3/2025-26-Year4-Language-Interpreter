# Year3-Language-Interpreter
This group project was done in year 3, where Me and a group implimented a interpreter for a made-up language.
Out of Courtsey for the Professor, this project is not in a runable state as all test files were removed
This code was made in coloberation with 3 other students but represents the following logic
Implemented a custom lexer in Java to tokenize a made-up language’s syntax. 
Built a semantic analysis phase to perform type checking, scope resolution, and error reporting. 
Developed a runtime traverser to execute control flow, function calls, and variable evaluation.
The grammar of the language was also removed to ensure information that could be used to reveal the project is kept secure.
